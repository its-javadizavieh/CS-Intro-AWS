# Introduzione e utilizzo AWS

**Introduzione e utilizzo AWS** - Complete course materials for learning networking, cloud computing, Docker and Kubernetes through practical exercises.

## 📚 About This Repository

This repository contains hands-on labs for a 30-hour course on **Amazon Web Services - Introduzione e utilizzo**. The materials are designed for practical learning with AWS Academy Learner Lab and local networking and container exercises.

Use only the Academy session and parameters documented by each lab. Do not use personal credentials, real data, or resources outside the exercise scope.
